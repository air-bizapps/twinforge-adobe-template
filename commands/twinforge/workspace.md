Use a skill `twinforge-workspace` para executar este comando: o fluxo de conectar o repositório GitHub do projeto à instância (workspace do projeto e segredo com o PAT).

Argumentos recebidos: $ARGUMENTS

Este comando só roteia para a skill. Não execute nada do `twinforgecli` por conta própria; siga as regras da skill, incluindo a seleção da instância da sessão, a confirmação antes de qualquer escrita e a regra de que o token nunca passa pela conversa.
