# Context

This bundle file is intentionally short. Don't look for project background
here:

* Domain, platform, team, known debt: `./CONTEXT.md` at the root of the
  Bunge-Magento2 repo (`git show origin/twinforge:CONTEXT.md` if the file is
  missing).
* Theme facts you need on every task: your own `AGENTS.md`.
* Frontend patterns and anti-patterns with file:line (accessibility,
  performance, `!important` hot spots): skill `bunge-frontend-code-quality`.
* Subtask format: skill `projeto-subtask-contract`.

Earlier versions kept a full copy of the frontend audit here and in
`AGENTS.md`; the copies drifted, so they were removed (2026-10-15).
