# Context

This bundle file is intentionally short. Don't look for project background
here:

* Domain, platform, modules, data conventions, testing, known debt:
  `./CONTEXT.md` at the root of the Bunge-Magento2 repo
  (`git show origin/twinforge:CONTEXT.md` if the file is missing).
* Per-module detail (entry points, tables, queues): `docs/module-index.md`.
* Backend patterns and anti-patterns with file:line: skill `bunge-backend-code-quality`.
* Your procedure: your own `AGENTS.md`; subtask format: skill `projeto-subtask-contract`.

Earlier versions kept a full copy of the codebase audit here and in
`AGENTS.md`; the copies drifted from the repo's `CONTEXT.md`, so they were
removed (2026-10-15).
