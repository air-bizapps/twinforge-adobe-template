# HEARTBEAT

This bundle file is intentionally short. On the `pi_local` adapter only
`AGENTS.md` reaches the agent's prompt; this file is stored with the
instructions but never read, so rules kept only here were silently ignored.

Where it lives now: the heartbeat procedure: the TwinForge skill (wake context, assignments, checkout, exit) plus the "First check, every heartbeat" section and the rest of your own `AGENTS.md`.

Earlier versions held a generic checklist here, which had drifted from
`AGENTS.md` (escalation to "the CEO", a "leave code better" habit that
contradicts the minimal-change rule). Behaviour that mattered was moved to
`AGENTS.md` and the rest removed (2026-10-15). See
`context/engenharia-de-contexto-e-prompt.md` in the <repo-de-configuracao> repo.
