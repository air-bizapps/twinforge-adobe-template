# docs/

Documentação de domínio do projeto (regras de negócio, fluxos, integrações). Este template **não traz** a documentação de nenhum cliente: ela é específica de cada projeto.

Preencha esta pasta com o conhecimento de domínio do seu projeto e referencie-a em `context/` e nos `AGENTS.md` dos agentes. O pacote de skills `twinforge` está documentado em [`twinforge-skills.md`](./twinforge-skills.md).
